# Easy Finder Product

Vehicle-first parts lookup as a mobile home-screen app (offline-capable PWA).

Open the published HTTPS link on your phone, then:

- **Android (Chrome):** menu → Add to Home screen / Install app
- **iPhone (Safari):** Share → Add to Home Screen

Dark mode follows the phone setting and can be toggled in the header. A sun/moon button remembers your choice.

To update the catalogue later: rebuild the app from the latest catalogue and push to this repository (the workflow publishes the `gh-pages` site).
